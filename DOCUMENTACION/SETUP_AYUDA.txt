================================================================================
  📋 PASOS PARA DESPLEGAR
================================================================================

PASO 1: Crear cuenta AWS (si no tienes)
  → https://aws.amazon.com

PASO 2: Crear usuario IAM con credenciales
  → AWS Console → IAM → Users → Create user
  → Nombre: "registro-participantes-dev"
  → Copiar Access Key ID y Secret Access Key

PASO 3: Instalar herramientas
  → AWS CLI, AWS SAM, Docker

PASO 4: Configurar AWS CLI
  → aws configure
  → Ingresar credenciales

PASO 5: Ejecutar script de despliegue
  → bash scripts/setup-aws.sh (o .ps1 en Windows)

PASO 6: Crear tablas en BD
  → RDS Query Editor
  → Ejecutar: scripts/init-database.sql

PASO 7: Testing
  → Abrir frontend en navegador
  → Crear un participante
  → Verificar que aparece en la lista

PASO 8: Monitoreo
  → Ver logs: sam logs -n FastAPIFunction --tail
  → Ver métricas en CloudWatch
